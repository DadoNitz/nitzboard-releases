### What it does

- **Many agents, one board.** Open Claude Code, Codex, Gemini or Kimi consoles on an infinite canvas and watch them all at once.
- **Agents that talk to each other.** A main console can spawn sub-agents, hand them tasks and collect the results. Agents can ask each other for a second opinion.
- **Everything next to the code.** Built-in browser for localhost previews, Markdown notes with checkboxes, kanban boards and a file viewer, all as nodes on the canvas.
- **Pick the right model.** Shows how much of the 5-hour and weekly limits each account has used, so heavy work goes where there is room.
- **Views for big sessions.** Auto-arrange, fit to screen, a mission map and a 3D office view of your agents.

### Install

| Platform | File |
|---|---|
| Windows 10/11 | `NitzBoard-Setup.exe` |
| macOS (Apple Silicon) | `NitzBoard-arm64.dmg` |
| macOS (Intel) | `NitzBoard-x64.dmg` |

Download from [the latest release](https://github.com/DadoNitz/nitzboard-releases/releases/latest). The app updates itself when a new version is published.

You need at least one agent CLI installed and logged in (for example `claude`, `codex` or `gemini`).
